# 🥗 Calorie & Meal Planner Web App

A Flask-based app that predicts daily calorie needs, generates AI-powered meal plans, and provides food nutrition info.

---

## 🚀 Features

- 🔐 User Signup/Login (MySQL)
- ⚖️ Calorie Prediction (ML model)
- 🧠 Meal Plan Generation (OpenAI GPT-3.5)
- 🍴 Nutrition Info Lookup
- 🕒 View Previous Predictions
- 🔁 Zigzag Calorie Plan

---

## 🛠 Tech Stack

- Python, Flask, HTML/CSS
- MySQL for user data
- Pickle model for calorie prediction
- OpenAI API for meal planning
- `.env` for environment variables
